# 删除手机通讯录重复联系人

## 结论

云端 Agent **无法直接读写手机通讯录**。可行做法：

1. **优先**：Google 通讯录网页 →「合并与修复」（安卓 Google 同步用户最快）
2. **通用**：手机导出 `.vcf` → `contacts_dedupe.py` 去重 → 备份后导入干净文件

## 仓库脚本

- 脚本：`contacts_dedupe.py`
- 说明：`CONTACTS_DEDUPE.md`
- 测试：`python3 -m unittest test_contacts_dedupe.py -v`

合并键：规范化手机号（去 `+86`/空格/横线）> 邮箱；同组合并 FN/TEL/EMAIL/ORG/NOTE。

```bash
python3 contacts_dedupe.py 通讯录.vcf --dry-run
python3 contacts_dedupe.py 通讯录.vcf -o contacts_clean.vcf
```

## 操作注意

- 导入前务必保留原始 `.vcf` 备份
- 手机里已有全量联系人时，直接再导入容易二次重复；更稳是「以云端主库合并」或「清空后再导入干净文件」
- 厂商账号（华为/小米/OPPO）优先用各自云服务的「合并重复」功能
